Judul Proyek

Program Rekap dan Analisis Nilai Matematika Kelas

1. Deskripsi Proyek

Program ini dirancang untuk membantu proses rekapitulasi dan analisis nilai matematika siswa. Program dapat dirancang untuk membaca data nilai dari file, memvalidasi nilai, menghitung rata-rata, menentukan nilai tertinggi dan terendah, serta menentukan status kelulusan berdasarkan Kriteria Ketuntasan Minimal (KKM).

2. Tujuan Proyek

1. Mempermudah proses rekapitulasi nilai siswa.
2. Menghitung rata-rata nilai secara otomatis.
3. Menentukan nilai tertinggi dan terendah.
4. Menentukan status kelulusan siswa.
5. Menyimpan hasil analisis ke dalam file teks.

3. Fitur Program

- Membaca data nilai dari file.
- Memvalidasi nilai dalam rentang 0–100.
- Menghitung rata-rata nilai.
- Menentukan nilai tertinggi dan terendah.
- Menentukan status kelulusan.
- Menyimpan laporan hasil analisis.

4. Batasan Proyek

- Program berbasis terminal atau console.
- Menggunakan bahasa pemrograman Python.
- Nilai siswa berada pada rentang 0 sampai 100.
- KKM awal ditetapkan sebesar 60.
- Data dibaca dari file teks.
- Laporan disimpan dalam file teks.
- Program tidak menggunakan GUI atau aplikasi web.

5. Input, Proses, dan Output

Input

- Nama siswa.
- Nilai matematika siswa.
- Data nilai dari file teks.

Proses

- Membaca dan memvalidasi data.
- Menghitung rata-rata nilai.
- Menentukan nilai tertinggi dan terendah.
- Menentukan status kelulusan berdasarkan KKM.

Output

- Daftar nilai siswa.
- Nilai rata-rata.
- Nilai tertinggi dan terendah.
- Status kelulusan siswa.
- File laporan hasil analisis.

6. Struktur Program

- "main.py": menjalankan alur utama program.
- "data_io.py": membaca data dan menyimpan laporan.
- "analisis.py": menghitung statistik nilai dan menentukan kelulusan.
- "utilitas.py": menyediakan fungsi pendukung.
- "nilai_contoh.txt": menyimpan contoh data nilai.
- "test_case.md": berisi rancangan skenario pengujian.
- "proposal.md": berisi rancangan proyek.
- "output/": tempat penyimpanan laporan.

7. Algoritma Singkat

1. Mulai.
2. Membaca data nilai dari file.
3. Memeriksa ketersediaan file.
4. Memvalidasi nilai siswa.
5. Menghitung rata-rata, nilai tertinggi, dan nilai terendah.
6. Menentukan status kelulusan setiap siswa.
7. Menampilkan hasil analisis.
8. Menyimpan laporan ke file teks.
9. Selesai.

8. Rancangan Pengujian

Pengujian awal mencakup nilai normal, nilai minimum, nilai maksimum, nilai di luar batas, file yang tidak ditemukan, status kelulusan, dan input yang bukan angka.

Rincian skenario pengujian terdapat pada "tests/test_case.md".
